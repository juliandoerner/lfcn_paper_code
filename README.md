# LEAPFROG CRANK–NICOLSON DECOUPLING OF WAVE–HEAT-TYPE PROBLEMS


> This software is published for reproducibility, following the guidelines for safeguarding good research practice of the Deutsche Forschungsgemeinschaft (DFG). It contains the source code, a version-pinned environment and the parameter sets needed to regenerate the reported results.

Each directory contains the software for reproducing the experiments of a certain subsection of the paper.
A reproduction environment with version pinned software packages is contained in each, and described in detail in the respective README.md.
